# Tier 1 Optional Location Page: Activation Note

The Tier 1 public website core remains fixed at exactly three routes: `/`, `/services`, and `/request`. The user authorized the optional Location Page for this Paws+Pine demo, so `/location` is active as an explicit optional-page extension.

For production client work, the optional page may be deployed as a **separate approved property**—for example, on a client-approved subdomain or separate destination—and should not be added to the three-route Tier 1 core unless explicitly authorized. The provider configures the selected option after the client supplies and approves the business name, brand assets, address or service area, hours, directions/map URL, contact details, consent/policy wording, and domain/hosting direction.

The Location Page uses only approved information. It does not create, verify, or manage a Google Business Profile or Google Maps listing, and it makes no search-visibility promise.
